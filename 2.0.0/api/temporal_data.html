Temporal Data Module¶

The temporal data module supplies the common time/frame interface used by imagery, detections, and tracks.

Core Classes¶

temporal_data.TemporalData

Represents an object which can hold temporal data such as times and frames

TemporalData requires at least one one-dimensional temporal coordinate:

  • times as a NumPy datetime64 array;

  • frames as a one-dimensional integer array.

If both are provided, they must have the same length. get_index() supports exact lookup or lookup of the nearest preceding value, which is used to align sparse imagery to the display timeline.

Basic Usage¶

import numpy as np

from vista.temporal_data.temporal_data import TemporalData

data = TemporalData(
    times=np.array(["2026-01-01T00:00:00", "2026-01-01T00:00:01"], dtype="datetime64[ns]"),
    frames=np.array([10, 20]),
)

exact_index = data.get_index(20, is_time=False)
preceding_index = data.get_index(15, is_time=False, nearest=True)

fill_times_frames(times, frames)[source]¶

Fill in missing times from frames, or missing frames from times, using this object’s own times and frames

The conversion is only performed when this object has both times and frames, exactly one of the inputs is provided, and every provided value is found in this object (via get_index). Otherwise the inputs are returned unchanged.

Parameters:

  • times (NDArray[np.datetime64], optional) – Times to find matching frames for, or None

  • frames (NDArray[np.int_], optional) – Frames to find matching times for, or None

Returns:
